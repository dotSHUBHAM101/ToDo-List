# Task Manager - To Do List

A clean and minimal task management app built with React.

## Features
- Add tasks instantly by typing and pressing Enter or clicking Add
- Mark tasks as complete with a checkbox — completed tasks get strikethrough
- Remove tasks with a single click
- Empty state message when no tasks are present
- Persists your focus with a clean distraction-free UI

## Tech Stack
- React
- useState for state management
- CSS for styling
- Html
- Javascript
